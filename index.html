Problem

営業活動でこんなお悩みありませんか？

「業界リストにとりあえずDMを送る」から卒業し、今まさに検討している企業だけに集中投下しませんか。

リスト作成に時間だけかかって成果が出ない

決算書や企業データベースをかき集めてリストを作っても、 「そもそも今検討していない企業」ばかりに送ってしまい、歩留まりが上がらない。

オンライン広告では届かない企業が多い

広告の閲覧・クリックログはあるのに、実際に決裁権を持つ担当者には届いていない。 情報収集はしているのに、Web上で捕まえきれていない。

「自社に興味がある企業」がどこか分からない

サイト訪問や資料閲覧などの行動は起きているのに、 「どの企業がいつ動きそうか」を可視化できず、営業の優先度付けができていない。

What is 「シラレル郵送DM」？

Web上のインテントデータ × 郵送DMで、
「いいタイミングだけ」に刺さるBtoBアプローチを。

Features

3つの特徴で、DM1通あたりの価値を最大化

「誰に」「いつ」「何を」送るかをインテントデータでコントロールし、無駄打ちを減らします。

Feature 01

数百万社規模の法人データベース × 行動ログで「今」動いている企業だけを抽出

国内の企業データベースとWeb行動ログを掛け合わせることで、 「条件は合うが検討していない企業」と「条件も合っており検討している企業」を分けて捉えることができます。

  • 業種・売上規模・従業員数などの基本属性に加え、「検討度合い」の軸でもスコアリング。
  • 「競合サービス名 × 資料請求」など、具体的な検索行動から絞り込みが可能。
  • 現場で営業リストを作る工数を削減し、アポ取得や商談に時間を割けるようになります。
Feature 02

リアルタイムに近い検知で、「検討の熱」が冷める前にDMを投函

検討シグナルを日次〜週次で集計し、スコアが一定以上に達したタイミングで対象企業を抽出。 「まとめて送る」のではなく、「熱が高い期間に間に合わせて送る」運用が可能です。

  • 直近30日・60日など、商材特性に合わせた検討期間を設計可能。
  • オンタイムに近いスコアリングで、Web広告との連動施策も実施しやすくなります。
  • 発送単位ごとのスコアをレポートで可視化。次回の配信条件チューニングに活かせます。
Feature 03

クリエイティブからリスト設計・効果検証まで、専任チームが伴走

「インテントデータをうまく使えるか不安」「DM施策の経験が少ない」といった場合でもご安心ください。 業種別の定番成功パターンをもとに、企画〜実行〜レポートまで伴走します。

  • クリエイティブ制作のテンプレートもご用意。初回からスピーディに立ち上げ可能。
  • 商談化・受注化までの指標を分解し、「どのフェーズを改善すべきか」を整理してご報告。
  • 継続配信を前提とせず、まずは小規模テストからのスタートも歓迎です。

導入事例

オンライン広告だけでは届いていなかった企業へのアプローチにご活用いただいています。

SaaS企業 A社様（人事システム）
従業員規模：100〜300名 / 送付通数：3,000通

Web経由のリードは一定数獲得できていたものの、「検討度の高い企業にもっと深く説明したい」という課題がありました。 インテントスコアの高い企業に限定して郵送DMを送付した結果、通常の業界一斉DMと比較して 問い合わせ率が約2.8倍に向上しました。

オンライン×オフラインの連動
人材紹介会社 B社様
対象：採用強化中の企業 / 送付通数：5,000通

既存のテレアポリストが枯渇しつつある中で、「今まさに採用活動を強化している企業」に集中したいというニーズから導入。 「採用代行」「中途採用支援」の情報を積極的に検索している企業に絞り、 DM経由でのオンライン面談申込が安定的に発生するようになりました。

営業リストの再構築
コンサルティング会社 C社様
対象：地方中堅企業 / 送付通数：2,000通

地方の中堅企業との接点づくりを目的に、オンライン広告ではリーチしきれない企業に郵送DMで接触。 Web行動データから「補助金」「事業承継」などの情報収集が活発な企業を抽出し、 DM経由でのセミナー参加・個別相談の申込を獲得しました。

FAQ

よくあるご質問

「まだ導入を決めていない」「情報収集中」という段階でのご相談も歓迎しています。

どのような業種・商材に向いていますか？
＋
SaaS・人材・コンサルティング・アウトソーシング・金融など、検討期間が一定以上あり、 比較検討が発生しやすい商材と相性が良いです。 一方で、衝動的に決まるような小額商材よりは、単価が高く検討に時間がかかる商材で効果を発揮します。
インテントデータの取得元や仕組みについて教えてください。
＋
提携パートナーが保有するWeb行動データを元に、企業の属性情報と照合してスコアリングを行っています。 具体的な取得元や計測方法については、個別のご商談にて開示可能な範囲でご説明いたします。 個社が特定される形でのレポートや、個人情報の特定は行っていません。
最低ロットや予算の目安を教えてください。
＋
最低ロットは概ね1,000通からのご案内となりますが、テスト内容やターゲット条件によって変動します。 予算の目安としては、1,000通で数十万円〜を想定いただけるとスムーズです。 まずはご希望の対象数・予算をお伺いした上で、最適な設計をご提案いたします。
自社の既存顧客リストやMAツールと連携できますか？
＋
はい、可能です。既存の顧客リストや商談リストと、インテントスコアを掛け合わせることで、 「既存顧客の中で再提案すべき企業」や「休眠リードの中で検討が再燃している企業」を抽出することもできます。 具体的な連携方法は、利用中のツールやデータ形式によって個別にご相談させてください。
まずは情報収集だけでも相談できますか？
＋
もちろんです。「今すぐの導入は未定だが、選択肢として理解しておきたい」という段階でのご相談も歓迎しております。 具体的な時期や予算が決まっていない場合でも、「自社の商材と相性が良さそうか」を一緒に整理することができます。
